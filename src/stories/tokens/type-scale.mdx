# The type scale

## The rungs

The scale has {TYPE_SCALE.length} rungs. Each rung answers to a class made of `text-` plus the rung
name, listed in the second column below.

## Why the scale is named

The rungs are declarations on `:root`, not utilities, so `calc(var(--text-base) * 2)` resolves and
the class is only a name for the step. The stock component text was shifted one rung up, so a
component that read the small rung now reads the base rung and still renders at the same px.

## Specimens

Each row renders its rung at the size and line height in the third and fourth columns.
